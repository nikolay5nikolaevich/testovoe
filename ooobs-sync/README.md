# Мини-синхронизатор заявок

- `GET /` и `GET /api/clients` — результат строго в формате ТЗ (`clients` + `stats`).
- `GET /api/dropped` — заявки с невалидным телефоном (id, имя, исходный номер).

Заявки забираются с `https://test.ooobs.ru/api/orders` при запросе (кэш 60 с; при сбое источника отдаётся последний удачный результат). Результат — чистая функция от входных данных, поэтому повторные запросы идемпотентны.

Правила: телефон -> `+7XXXXXXXXXX` (ровно 11 цифр, первая 7 или 8), иначе отбрасывается; дубль по телефону -> максимальный `amount`, при равенстве более поздний `created_at`.
